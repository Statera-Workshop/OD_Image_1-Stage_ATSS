# OD_Image_1-Stage_ATSS

**ATSS - Image track - training and test evaluation**

Part of the *Physical AI Object Detection* reference series of the **Statera Working Group**:
one algorithm and one task per repository, the same data, protocol and metrics for every algorithm -
only the algorithm differs.

## Model

- Paper: Zhang, Chi, Yao, Lei & Li, *Bridging the Gap Between Anchor-based and Anchor-free Detection via ATSS*, CVPR 2020
- Implementation source: official sfzhang15/ATSS (maskrcnn-benchmark plumbing replaced by plain tensors)
- Parameters: 32.20 M (36 classes)

- ResNet-50 + FPN P3-P7
- GN head, 1 anchor (8S) per location, centerness, learnable scales

Detection layer / assignment / loss: ATSS assignment (top-9 per level, IoU mean + std); focal + 2 x centerness-weighted GIoU + BCE centerness

Differences from the original (common protocol):

- No ImageNet weights, common init, no mean / std, 608 input, Adam with the common schedule, common augmentation and post-processing (see [Unified] markers)
- PreciseBN before every evaluation and the final save (micro batch 2 BN statistics; RetinaNet test mAP50 0.148 -> 0.849 for the same weights)

## Data: FashionLetters36 (synthetic, generated by step 1)

36 classes = Fashion-MNIST (10) + EMNIST letters (26); 608 x 608 canvases with 3-10 non-overlapping objects of 32-160 px; 4,096 train / 1,024 test images, fixed seed - every user generates the same dataset. Purpose: verify that the algorithm is implemented correctly (it must converge on this controlled data), separately from benchmarking on VOC / COCO.

EMNIST is downloaded from NIST; if the download is refused, fetch `gzip.zip` in a browser from https://www.nist.gov/itl/products-and-services/emnist-dataset and run `python data_processing_fl36.py --emnist-zip <path>/gzip.zip`.

## Results

Test set: FashionLetters36 test (1,024 images, 36 classes), IoU 0.5, after 30 epochs (2.4 h on an RTX 4070 Laptop GPU).

| mAP50 | Recall | Final train loss | Train class accuracy |
| --- | --- | --- | --- |
| **0.8639** | 0.936 | 0.799 | 81.6 % |

Convergence (test mAP50):

| Epoch | 5 | 10 | 15 | 20 | 25 | 30 |
| --- | --- | --- | --- | --- | --- | --- |
| mAP50 | 0.688 | 0.767 | 0.775 | 0.792 | 0.837 | 0.864 |

Protocol: 30 epochs, Adam lr 1e-4 (constant), effective batch 8 (micro batch 2 x 4 accumulation), input 608, seed 777, no pretraining; augmentation: horizontal flip + the basic YOLO-paper augmentation (random scale / translation 20 %, HSV hue 0.1, saturation / exposure 1.5); test mAP50 every 5 epochs.

## Usage

```bash
pip install -r requirements.txt
python data_processing_fl36.py          # downloads Fashion-MNIST + EMNIST, generates FashionLetters36
python train_image_atss.py               # training, then test evaluation (runs/image_atss/)
python evaluate_image_atss.py            # test evaluation of runs/image_atss/checkpoints/ (or --weights <file>)
```

Data are expected under `$PHYSICAL_AI_ROOT/datasets` (default `~/Physical_AI/datasets`).
Smoke test: `python train_image_atss.py --epochs 1 --max-train 8 --max-test 4`.

Trained weights: the GitHub Release of this repository contains `image_atss_fl36_e030.pth` (the run reported above).
Put it into `runs/image_atss/checkpoints/` or pass `--weights <file>` to the evaluation script.
Demo scripts using these weights will be added in a later release.
